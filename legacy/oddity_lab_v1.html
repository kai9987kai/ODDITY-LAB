Interpretation protocol

Scores are prequential: each prediction is scored before its label trains the readout. The baseline and candidate receive identical stimuli and noise. Grafts can help, hurt, or make no difference; no outcome is scripted.

Inspect the actual model / equations
xᵢ′ = tanh(0.62xᵢ + 0.58ΣⱼWᵢⱼaⱼ + 0.7uᵢs + 0.35yᵢ + 0.24zᵢ + 0.22fᵢ + εᵢ)
yᵢ′ = tanh(0.86yᵢ + 0.24xᵢ + 0.27ΣⱼWᵢⱼaⱼ)
zᵢ′ = 0.91zᵢ + 0.09ΣⱼWᵢⱼsin(φᵢⱼ)aⱼ
fᵢ = ΣⱼWⱼᵢaⱼ
aᵢ = 0.7xᵢ + 0.3yᵢ (dual enabled); otherwise xᵢ
p = sigmoid(b + Σᵢvᵢaᵢ)
vᵢ ← vᵢ + η(target − p)aᵢ

Terms y, z, and f are zero when the respective candidate module is disabled. Baseline uses x only. Plasticity performs clipped Hebbian updates and occasionally replaces the weakest active edge. Activations are bounded by tanh. Noise is shared. The same 24-node recurrent reservoir and readout size are used for both agents.

Synthetic computational toy, not a biological claim or scientific validation of dual-soma neurons. A single seed, a short run, or a large apparent accuracy gap is insufficient evidence; repeat seeds, test ablations, and examine CSV trajectories. Manual shocks deliberately break equal conditions from that point onward.
